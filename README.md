# B站播放器增强工具箱

一个集中改善 Bilibili 网页播放器观看体验的用户脚本。当前版本为 v3.2.0，支持普通视频、番剧、合集页面和新版 Web Components 播放器。

## 功能

1. **自动跳片头片尾**：按 `Shift + M` 设置片头时间和片尾时长，支持 `mm:ss`、秒数和中文冒号 `：`。
2. **快速开关跳过功能**：按 `O` 开启或关闭自动跳转，并记住上一次设置和开关状态。
3. **快捷切换中文字幕**：按 `C` 开启中文字幕；再次按下可关闭当前中文字幕。脚本会记住字幕状态，并在刷新或播放器重建后自动恢复。输入文字时不会误触。
4. **选集列表增强**：自动为各分 P 添加 `P1`、`P2` 等序号；刷新页面后，合集列表会滚动到当前正在播放的分片，确保它处于可见范围。
5. **字幕快捷键提示**：播放器字幕按钮会显示 `字幕 (c)`，方便记忆快捷键。
6. **字幕画中画**：检测到画中画模式菜单时，优先选择支持字幕的“新版画中画”。
7. **广泛兼容**：支持 `video`、`bangumi/play`、`list` 页面，兼容 Shadow DOM、原生全屏浮层及 SPA 切换后的播放器重建。
8. **弹幕两档切换**：按 `D` 只在开启和关闭弹幕之间切换，自动跳过精简弹幕；当前为精简弹幕时，按一次关闭。输入文字、使用组合键或长按时不会误切换。
9. **可配置的播放默认状态**：按 `Shift + O` 设置启动提示、弹幕和字幕的默认行为；设置会持久保存，并对 SPA 换集或切换推荐视频生效。

## 设置

在 B 站视频页按 `Shift + O` 打开设置入口，再输入编号选择以下设置项。选择后播放器右下角会显示简短提示。设置保存在 B 站页面的本地存储中，不依赖用户脚本管理器的特权 API，因此 Tampermonkey 和 Violentmonkey 均保持页面上下文运行。

| 设置项 | 可选值 | 默认值 |
| --- | --- | --- |
| `设置：启动提示` | 仅在 `O`、`Shift + M` 等快捷键操作时显示；打开视频即显示 | 仅快捷键操作时显示 |
| `设置：弹幕默认状态` | 不处理；打开视频时默认关闭 | 不处理 |
| `设置：字幕默认状态` | 不处理；打开视频时默认关闭 | 不处理 |

“弹幕默认关闭”会在每个视频开始时关闭弹幕；之后通过播放器按钮或 `D` 键打开时会使用全部弹幕状态，不会停在精简弹幕。“字幕默认关闭”会关闭普通字幕和 AI 字幕，并在同一视频内尊重用户之后通过原生字幕按钮或 `C` 键进行的选择。“字幕不处理”保留原有的字幕状态记忆与恢复行为。

## 安装

1. 前提：已安装 Tampermonkey、Violentmonkey 或其他支持用户脚本的扩展。
2. 方法一：点击链接直接安装：https://raw.githubusercontent.com/mankaki/bilibili-player-toolkit/main/bilibili-player-toolkit.user.js
3. 方法二：通过 Greasy Fork 安装：https://greasyfork.org/zh-CN/scripts/539778-b%E7%AB%99%E8%87%AA%E5%8A%A8%E8%B7%B3%E7%89%87%E5%A4%B4%E7%89%87%E5%B0%BE

旧版 `bili_skipper.user.js` 安装地址会继续提供兼容入口，并自动加载新版脚本。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Shift + M` | 设置片头时间和片尾时长 |
| `Shift + O` | 打开工具箱设置 |
| `O` | 开启/关闭自动跳片头片尾 |
| `C` | 开启/关闭中文字幕 |
| `D` | 开启/关闭弹幕（跳过精简弹幕） |
